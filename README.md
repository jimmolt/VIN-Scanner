# VIN Scanner

Take a photo of a VIN (windshield or door post) and the page reads it, checks the VIN check digit, and looks up the vehicle on NHTSA. Shows a full VIN report: every spec NHTSA decodes, recalls, owner complaints, crash ratings, EPA fuel economy and a VIN breakdown. Save VINs to a database (Saved VINs tab) linked to a customer list (Customers tab), with CSV export and backup. Data is stored in the browser on each device. Single-file HTML app, built for phone use.

Live: https://jimmolt.github.io/VIN-Scanner/
